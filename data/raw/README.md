# Authorized local source only

The distributable project intentionally omits the original CSV. The source, consent,
device linkage and redistribution license were not supplied. This is not a finding
that the data are illegal; redistribution permission simply cannot be verified.

For an authorized rerun place `FINAL_dataset_with_fitbit.csv` here, set
`CARDIO_DATA_PATH`, or pass `--data /path/to/FINAL_dataset_with_fitbit.csv`.
The included trained models, aggregate reports and invented demo patient run without
the CSV. Model artifacts are research outputs; review source-data terms before
publishing any derived model. The software license does not grant data rights.
